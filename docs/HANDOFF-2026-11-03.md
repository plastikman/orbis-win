## Change

The title already restarts into its launcher when `__wine_main` returns, and
Options+Create remains the manual close fallback. A game that exits normally
can leave Wine's in-process server alive, however, so the PS4 continues to
show Wine's desktop until the user force-closes the title.

The Wine server now writes `PW_PS5_NO_USER_PROCESSES` when its normal idle
shutdown fires after all guest processes have ended. The title receives this
through its existing captured Wine stderr channel and uses its existing
relocatable `sceSystemServiceLoadExec` path to restart into the launcher. The
signal is emitted after Wine's server shutdown cleanup, rather than terminating
the title from inside a server callback.

- Upstream-shaped patch: `prospero-win/wine/patches/0112-server-ps5-return-title-when-guest-processes-exit.patch`.
- PS4 source patch: `src/wine-patches-ps4/1030-server-return-title-when-no-guest-process-remains.patch`.
- Title marker handling: `prospero-win/native/wine64_main.c`.
